# ИИ-юрист на базе Qdrant + Ollama

Микросервис, который:

- отвечает на юридические вопросы на основе нормативно-правовых актов, загруженных в Qdrant;
- анализирует текстовые документы (`.txt`) и оценивает их соответствие законодательству,
  выставляя уровень риска: **Зелёный / Жёлтый / Красный** и объясняя свой выбор;
- возвращает ссылки на документы (файлы НПА), на которые опирался при ответе.

> ⚠️ ВАЖНО: сервис **не является** полноценной юридической экспертизой и не заменяет
> консультацию квалифицированного юриста. Это вспомогательный инструмент.

---

## Архитектура

Сервис строится на трёх компонентах:

1. **Qdrant** — векторное хранилище с коллекцией `docs`, куда загружены НПА.
2. **Ollama** — LLM-сервер с моделями:
   - `bge-m3` — генерация эмбеддингов;
   - `krith/qwen2.5-32b-instruct:IQ4_XS` — основная модель ИИ-юриста.
3. **Этот микросервис** (FastAPI) — связывает всё вместе:
   - получает вопрос или документ;
   - запрашивает эмбеддинги в Ollama;
   - ищет релевантные фрагменты в Qdrant;
   - генерирует ответ/оценку документа с опорой на найденные фрагменты.

## Возможности

### 1. Вопрос–ответ на основе НПА

`POST /ask`

- вход: текст вопроса;
- выход: краткий ответ + список источников (фрагменты НПА и пути к файлам).

### 2. Анализ текста документа (.txt)

`POST /analyze_document`

- вход: файл `.txt` (plain text);
- выход:
  - `grade`: `green` / `yellow` / `red`;
  - `grade_label`: `Зелёный / Жёлтый / Красный`;
  - `explanation`: краткое обоснование решения;
  - `recommendations`: что улучшить в документе;
  - `sources`: список документов/фрагментов НПА, на которые опирался ИИ.

## Зависимости

- Python 3.11+
- Docker / Docker Compose
- Запущенные отдельно:
  - **Qdrant** (по умолчанию `http://localhost:6333`, коллекция `docs`);
  - **Ollama** (по умолчанию `http://localhost:11434`), с установленными моделями:
    - `bge-m3`
    - `krith/qwen2.5-32b-instruct:IQ4_XS`

## Быстрый старт (Docker Compose)

1. Убедитесь, что Qdrant и Ollama уже запущены и доступны:
   - Qdrant: `http://localhost:6333`
   - Ollama: `http://localhost:11434`

2. Соберите и запустите сервис:

```bash
docker compose up --build
```

3. По умолчанию API будет доступно по адресу:

```text
http://localhost:8001
```
